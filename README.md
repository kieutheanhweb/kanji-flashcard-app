# 🀄 漢字フラッシュカードアプリ

**🖥 技術スタック:** React, JavaScript, CSS  
**🎯 対象ユーザー:** 日本語を学ぶ学生  

---

## 💡 プロジェクト概要

このプロジェクトは **漢字フラッシュカードアプリ** です。  
漢字を学ぶ学生向けに作られました。  

**主な機能:**  
- 表に漢字、裏に意味がある **フラッシュカード表示**  
- カードをクリックして **裏返す**  
- 自分で漢字と意味を **追加**  
- 追加した漢字の **履歴を確認**  
- 履歴から選択した漢字を **削除**  

Reactの **useState** と **useEffect** を使用しており、  
レスポンシブデザインで **PC・スマホどちらでも使いやすい** です。  

---

## 📁 機能詳細

### 1️⃣ フラッシュカード画面
- デフォルト漢字: **日, 学, 生**（削除不可）  
- カードをクリックして **裏返す**  
- 「次へ」ボタンで **次のカードに移動**  
- フォームで **新しい漢字を追加可能**  

### 2️⃣ 履歴画面
- ユーザーが追加した漢字を **グリッド表示**  
- チェックボックスで漢字を選択  
- 選択した漢字を **削除**  
- デフォルトカードは **削除できません**  

### 3️⃣ 保存機能
- ユーザーが追加した漢字は **localStorage に保存**  
- ページ更新後もデータは消えません  

### 4️⃣ レスポンシブデザイン
- PCとスマホ対応  
- 小さい画面ではカードサイズや文字サイズが自動調整

## 🛠 実行方法

1. リポジトリをクローン  
```bash
git clone https://github.com/your-username/kanji-flashcard-app.git
```

2. プロジェクトフォルダに移動  
```bash
cd kanji-flashcard-app
```

3. 依存パッケージをインストール  
```bash
npm install
```

4. アプリを起動  
```bash
npm run dev
```

5. ブラウザで確認  
```
http://localhost:5173
```
